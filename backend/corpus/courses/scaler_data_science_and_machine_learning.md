# Scaler Data Science and Machine Learning Program

## 1. Program Overview
The Scaler Data Science & ML Program is an 11-to-13 month comprehensive career track designed for working professionals and graduates aspiring to become Data Scientists, ML Engineers, or AI Engineers.

## 2. Curriculum Roadmap
- **Module 1: Mathematics & Applied Statistics for Data Science**: Linear algebra, matrix operations, multivariate calculus, probability distributions, hypothesis testing, A/B testing frameworks, and confidence intervals.
- **Module 2: Python, SQL & Data Wrangling**: Advanced Pandas, NumPy, visualization with Seaborn/Plotly, complex SQL queries, window functions, and data cleaning pipelines.
- **Module 3: Supervised & Unsupervised Machine Learning**: Linear/Logistic Regression, Decision Trees, Random Forests, XGBoost, LightGBM, K-Means Clustering, PCA, t-SNE, and feature engineering techniques.
- **Module 4: Deep Learning, Computer Vision & NLP**: Neural networks from scratch with PyTorch and TensorFlow, CNNs (ResNet, YOLO), RNNs, Transformers, BERT, LLM fine-tuning, and prompt engineering.
- **Module 5: MLOps and Production Systems**: Model deployment with FastAPI, containerization with Docker, MLflow for experiment tracking, and AWS/GCP cloud model hosting.

## 3. Real-World Capstone Projects
Learners build 5+ end-to-end portfolio projects including:
1. Recommendation Engine for an e-commerce platform.
2. Credit Card Fraud Detection system with imbalanced datasets.
3. Automated Document Summarizer using Transformer-based LLMs.
4. Computer Vision Automated Quality Inspector.

## 4. Prerequisites
- Basic familiarity with high school mathematics and logic.
- Prior coding experience is helpful but not mandatory, as the course begins with an introductory Python foundation track.
